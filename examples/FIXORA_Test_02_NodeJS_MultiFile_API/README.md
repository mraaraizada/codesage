# FIXORA Test Project 02 — Node.js User API

A deliberately buggy multi-file Node.js REST API.

## Requirements
- Node.js 18+
- No third-party dependencies

## Run tests
```bash
npm test
```
Tests should fail before the fix and pass after it.

## Run API
```bash
npm start
```
Try GET /users/1, GET /users/2 and GET /users/999.

See BUG_REPORT.md for the prompt to give FIXORA.
